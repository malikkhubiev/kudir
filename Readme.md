# КУДиР — ИП УСН 6% Доходы

Веб-приложение для учёта доходов, платежей и налогового календаря ИП на УСН 6%.
Запускается локально через FastAPI + SQLite.

## Быстрый старт

```bash
pip install fastapi uvicorn jinja2 python-multipart openpyxl
python kudir.py
```

Открыть: http://127.0.0.1:8000

## Что умеет

- **Доходы** — дата, сумма, контрагент, комментарий. Автоматически считает налог 6% и 1% свыше 300К.
- **Платежи (факт)** — фикс. взносы / 1% свыше 300К / налог УСН, с привязкой к году (`for_year`). Уменьшают налог автоматически.
- **Календарь (план)** — дела со сроками и статусом «готово». При первом запуске предзаполняется стратегией (25.12.2026 и 20.04.2027).
- **Переключатель года** — расчёт за 2026 / 2027 / любой доступный год.
- **Экспорт** — `.txt` (человекочитаемый) и `.xlsx` (4 листа: Сводка, Доходы, Платежи, Календарь).

## Логика расчёта

- Налог 6% = Доходы × 6%
- Уменьшение = уплачено фикс. взносов (за год) + уплачено 1% (за год)
- Налог к уплате = max(0, Налог 6% − Уменьшение)
- Налог остаток = Налог к уплате − уплачено налога УСН

Взносы и 1% уменьшают налог **того года**, за который они уплачены (`for_year` в платеже).

## Стратегия (по ТЗ)

1. Никаких авансовых уведомлений — **сначала декларация, потом платёж**.
2. 25.12.2026 — фикс. взнос за 2026 (окт–дек, ≈14 347,50 ₽).
3. 20.04.2027 — пачка: декларация за 2026, 1% свыше 300К, уменьшенный налог за 2026, аванс УСН за 1 кв. 2027.
4. Всё заранее — минимум за 5 дней до дедлайна.
5. Группируем дела в один день.

## Полезное

- **Сбросить базу** — удалить `database.db` и перезапустить. Календарь предзаполнится заново.
- **Экспорт** — кнопки вверху страницы, учитывают выбранный год.
- **Редактирование** — кнопка ✎ рядом с записью открывает модалку.
- **Из календаря в факт** — кнопка «→ Внести факт» подставляет данные в форму платежа.
- **Ошибки JS-линтера в VS Code** на `{% ... %}` — ложные, игнорировать (или поставить расширение Jinja).
